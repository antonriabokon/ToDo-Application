# ToDo Application

A simple ToDo application built with C# and WPF using XAML. Users can enter tasks and add them to a scrollable list.

This project demonstrates basic WPF concepts such as controls, event handling, layouts and dynamically adding UI elements.

## Setup

Clone the repository and open the solution in Visual Studio. Build and run the project. A Windows environment with the required .NET SDK is needed.

## Usage

Enter a task in the text box and click Create ToDo button. The task will be added to the list and the input field will be cleared automatically.
